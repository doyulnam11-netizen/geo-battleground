# 전투·공중 투입 업데이트

온라인 경기는 100m 높이의 수송기에서 시작합니다. Space/점프/뛰어내리기 버튼으로 투입하고 맵 x=-200m에서 +200m까지 12m/s로 이동하며 약 33.3초 뒤 반대편 끝에서 자동 투입합니다. 이동 중 언제든 뛰어내릴 수 있습니다. 하강 속도는 9m/s이며 이동으로 착륙 지점을 조절합니다. 착륙까지 공격·피해·획득을 막습니다. 연습 모드는 빠른 조작 연습을 위해 지상에서 시작합니다.

기존 AR/SMG/DMR에 SNIPER(머리100/몸70/팔다리42, 5발, 간격1.45초), SHOTGUN(8산탄 각 머리16/몸12/팔다리8, 거리감쇠, 6발, 간격0.95초)을 추가했습니다. 장비는 바닥에서 획득합니다. 조준경 버튼은 1/2/4/8배이며 서버가 유효 배율을 검사합니다. 온라인은 맨손으로 시작하며 5종 총과 2/4/8배 조준경은 바닥에서 파밍합니다. 가방에서 총을 장착/해제하고 보유 배율을 교체/해제합니다. 해제한 장비는 가방에 남습니다. 보유하지 않은 총/배율 장착과 맨손 발사를 서버가 거부합니다. 연습 모드에는 기본 총이 지급됩니다.

피격 붉은 화면·피격 문구·공격 방향과 명중 마커를 표시합니다. 서버 규칙 검사는 수행했지만 실전 다인 밸런스, 모바일 GPU 성능, 고급 수송기 내부/문 모션과 손으로 낙하산을 조작하는 모션은 미검증 또는 미구현입니다. 무기 모델과 수송기는 절차적 모델입니다.
