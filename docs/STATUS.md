## 중요한 구분

- 연습 모드의 5명은 로컬 AI입니다. 실제 참가자로 꾸미지 않습니다.
- 온라인 로비의 인원은 서버에 실제 연결된 세션입니다. 두 실제 WebSocket 연결의 통합 테스트가 있습니다.
- 기기 에뮬레이션 검사는 실제 Android/iPhone에서의 검사가 아닙니다.
- 절차적 그래픽은 기능적이고 스타일화된 수준입니다. 요청한 사진 같은 최종 그래픽 수준은 미완료입니다.
- 기본 물리 및 지연 보정은 근사 구현입니다. 전문 FPS 엔진과 같은 정밀도를 약속하지 않습니다.
- 실제 교과서 원문을 확보/대조하지 않았습니다. 원문 문항을 복제하지 않았으며 과학 개념 중심의 자체 문제입니다.
- 배포 설정을 작성한 것과 실제 서버를 배포한 것은 다릅니다. 실제 배포 여부는 전달된 URL과 테스트 보고서를 확인하세요.
